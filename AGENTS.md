# Project Guidelines

For behavior changes, load and enforce the `vericoding` skill at
[.agents/skills/vericoding/SKILL.md](.agents/skills/vericoding/SKILL.md).
Do not begin implementation until the domain model and requirement have been
discussed and agreed with the developer.

## Clarification Questions

Never use structured question dialogs. Instead ask questions in normal chat text
so the developer can reply freely.
